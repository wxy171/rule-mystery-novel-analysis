# 结构节奏与创作技法

> 本文提炼的是现有拆解档案中可迁移的写作机制，不建议照搬原作具体桥段、设定或措辞。

## 一、核心结构：从规则题升级为价值题

现有材料呈现出一条清晰的题型变化：

- 医院：识别规则、身份、职责边界与信息来源。
- 三口之家：识别认知差异、记忆、家庭关系与梦境机制。
- 现实追查：将副本线索转成现实证据和行动方案。
- 期末考试：面对他人困境，在感性、理性、程序和代价之间作选择。

有效的升级不是简单增加怪物强度，而是改变读者需要回答的问题。

## 二、规则设计的七个维度

每条规则至少要明确：
1. **对象：** 对谁生效？
2. **条件：** 什么情况下触发？
3. **范围：** 哪个地点、时间或身份状态？
4. **执行者：** 谁/什么负责惩罚？
5. **后果：** 违反后具体发生什么？
6. **信息来源：** 规则文本是否可信，是否可能被篡改？
7. **漏洞：** 是否存在职责边界、优先级、例外或定义歧义？

规则的张力来自不同规则之间的交叉，而不是数量堆积。

## 三、推演型主角的设计

### 让失败变成信息
每次失败至少完成一项：
- 排除一个错误假设；
- 确认一个触发条件；
- 发现一个隐藏执行者；
- 识别一个资源成本；
- 揭示一个人物关系或道德代价。

### 防止能力破坏悬念
- 明确精神力、时间、道具或寿命成本；
- 让推演依赖主角已有信息，错误前提会产生错误结论；
- 保留不可观测区域和认知污染；
- 把“知道怎么做”与“能否承受代价”分开；
- 避免重复展示大量相似死亡，只保留改变决策的分支。

## 四、单章模板

1. 章首给出具体异常或反常行为。
2. 明确本章可判断成败的即时目标。
3. 提供一至两条关键规则、证词或物件信息。
4. 暴露规则与现实、两份信息源之间的矛盾。
5. 主角提出一个可验证假设。
6. 通过观察、试探、询问、伪装或推演验证。
7. 失败或代价揭示原假设的缺口。
8. 获得可复用的信息增量。
9. 主角做出有代价的行动选择。
10. 章末用新异常或旧线索的新解释制造钩子。

## 五、副本单元模板

入口异常 → 生存压力 → 规则建立 → 初次误判 → 规则冲突 → 有限试错 → 中段升级 → 身份/世界观反转 → 终局行动 → 奖励与损失 → 人物关系变化 → 长线谜面推进。

每个副本至少更换一个核心题型，避免只把场景从医院换成学校，却仍然重复同一种解题流程。

## 六、可迁移的具体技法

| 技法 | 作用 | 使用检查 |
|---|---|---|
| 目标阶梯 | 让通关后仍有更高目标 | 生存、逃离、真相是否有区别？ |
| 失败换信息 | 让试错有叙事收益 | 每次失败是否改变下一次决策？ |
| 道具多功能 | 让前期细节在后期增值 | 道具是否同时影响行动与认知？ |
| 身份反转 | 重新解释前文规则 | 是否提前埋有可回看的证据？ |
| NPC关系变化 | 让人物不只是工具 | 主角是否为关系承担实际成本？ |
| 语义精确 | 让一个词成为关键条件 | 任务文字中的名词差异是否被认真对待？ |
| 情感锚点 | 让解谜拥有情感终点 | 情感物件是否在前文出现并建立意义？ |
| 现实回声 | 让副本结果影响现实 | 现实调查是否真正改变行动条件？ |
| 伦理两难 | 让规则题升级为价值题 | 选择是否有合理代价，而非简单标准答案？ |

## 七、避免的写作陷阱

- 规则过多，读者只能背诵，无法推理；
- 主角推演无限免费，悬念被能力吞噬；
- 反转只靠作者临时添加新设定；
- NPC只会机械执行规则，没有利益和关系；
- 情感线只在结尾煽情，前文没有物件、行为和记忆铺垫；
- 所有副本都采用同样的“读规则—找矛盾—推演—破解”节奏；
- 把角色猜测写成世界真相，破坏后续悬念。

## 八、原创写作时的自检问题

- 读者能否在主角揭晓前获得足够线索？
- 每条规则是否能通过行动验证？
- 主角是否可能因为错误前提而失败？
- 失败是否改变信息状态？
- 道具是否有前后呼应？
- NPC是否有独立目标？
- 反转能否同时解释多个早期细节？
- 最终选择是否暴露人物价值观？
- 副本结束后，人物关系或长期目标是否发生变化？
