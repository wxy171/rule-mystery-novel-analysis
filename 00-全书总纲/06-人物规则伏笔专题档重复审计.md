# 人物、规则、伏笔专题档及章节主档重复审计

> 审计日期：2026-11-18
> 审计对象：main 分支当前可见目录与专题档、终局章节主档
> 审计性质：内容结构审计；本文件不替代正文证据，也不把相同事实的必要交叉索引视为错误重复。

## 一、结论摘要

当前仓库的主要问题不是“同一段文字被机械复制到所有文件”，而是**专题档采用了按轮次追加补录的维护方式**：早期结论没有统一回写到唯一条目，后续又以新标题重复登记。由此产生三类问题：

1. 同一机制在同一专题档中多次出现，最新结论与旧结论并列，读者需要自行判断哪一条生效。
2. 人物、规则、伏笔专题档之间重复解释同一事实，边界不清。
3. 章节主档已经完整叙述事件，专题档又重复写成长段剧情摘要；跨文件可以保留事实索引，但不宜复制完整过程。

**处理原则：章节主档保留章节级证据和事件过程；专题档保留跨章节结论、机制边界、人物关系与伏笔状态。** 同一事实在专题档中只保留一个主条目，其余位置用章节号或专题路径交叉引用。

## 四、章节主档与专题档之间的重复

本次抽查终局章节主档与专题档，确认以下属于**合理的证据复用，但应压缩摘要**：

1. `chapters/530-553-出版社平行世界与暗月马戏团计划.md` 已逐章记录第537章遗忘、第548—549章马戏团建立、第551—553章孟想精神干预；规则档和伏笔档不需要再次复述场景过程，只需给出结论和章节定位。
2. `chapters/554-577-击败郝仁世界线收束与孟想往事.md` 已叙述郝仁唯心天赋、孟想童年与逃生天赋、塔罗资源和太阳牌治疗边界；人物档保留孟想弧线，规则档保留机制定义，二者都不应复制章节叙述。
3. `chapters/578-586-棋盘掀翻导演谢幕与作品之外.md` 已记录第579章太阳牌与小智告别、第580章孟想人类形态成本、第586章孟想回归；规则档只保留太阳牌与形态维持的机制结论，人物档只保留回归与关系变化。
4. `chapters/587-589-番外与孟想诊疗日记.md` 已详细叙述陈泽宇日记与第588—589篇诊疗事件；人物档和规则档应避免再次复制事件链，改为交叉引用。

**章节主档本身还有覆盖区间重叠：**
- `554-559-中二病与世界线收束.md` 与 `554-577-击败郝仁世界线收束与孟想往事.md` 覆盖554—559章。
- `578-580-后院失火与暗月谢幕.md` 与 `578-586-棋盘掀翻导演谢幕与作品之外.md` 覆盖578—580章。
- `581-586-未完成作品与直播终局.md` 与 `578-586-棋盘掀翻导演谢幕与作品之外.md` 覆盖581—586章。

这类重叠不能直接删文件：先比较独立补证、用户正文和版本差异。治理方向是确定一个正式主档，其他文件转为补证附件/历史版本或合并后删除；不能在未比较正文前清除。

## 五、建议执行顺序

1. **先治理规则档内部重复**：重复最明确，且不会影响章节原始证据；先合并遗忘、太阳牌、孟想能力和第588篇时序。
2. **再治理伏笔档**：建立唯一伏笔条目，将多轮状态更新收束到当前状态；历史审计保留为变更日志。
3. **再治理人物档**：合并孟想条目、诊疗线和第565章补证；其余人物按同一结构处理。
4. **最后处理章节主档重叠**：比较三个重叠区间的正文、证据等级、用户提供文本和补证差异，再确定正式主档。
