这些只能作为后续阅读导航，不能据此写成剧情事实。

## 04｜开篇拆解：逐拍分析

### 4.1 第一章：先让读者进入危险，再解释规则

【正文核验】

开头以房间、发黄墙壁、血迹、头发、残肢等具体视觉细节构建现场。它先给读者一个可感知的异常空间，而不是先讲一大段世界观。

**逐拍：**
1. **感官冲击**：用可见的物质细节迅速确立恐怖类型。
2. **主角同步入局**：顾毅醒来，读者与主角一起确认处境。
3. **外部 stakes**：副本失败不仅是个人死亡，还会牵连所属国家。
4. **先死一次**：主角第一次尝试即失败，让规则具备可信的杀伤力。
5. **能力登场**：无限推演为主角提供重新尝试的可能。
6. **成本约束**：精神力消耗、创伤记忆保留，避免能力失控。
7. **目标分层**：普通、优秀、完美三档目标让故事从生存向调查延伸。

### 4.2 第二章：待核验的拆解任务

【目录确认】标题为《互相矛盾的规则》。

**当前只能提出核验问题：**
- 两套规则分别来自什么载体？
- 是否明确给出相互矛盾的命令？
- 主角是否立即发现矛盾，还是先执行后受罚？
- 冲突是字面矛盾，还是适用条件不同？
- 章末是否留下一个具体可检验的判断？

在正文补齐前，不把后续章节中的规则信息倒灌成第二章事实。

### 4.3 第三章：能力管理与关键疑问

【正文核验】

顾毅开始意识到推演资源有限，回顾此前尝试，思考如何减少无效模拟；同时注意到“第二个病友”始终没有被自己看见。

**功能：**
- 把能力成本从设定变成主角主动管理的策略；
- 把一个“没出现的人”变成负信息线索；
- 让读者开始怀疑：缺席本身是否就是异常。

### 4.4 第四—五章：从困境到行动

【正文核验】

早餐事件以“病友出事”为核心，把规则执行与救人伦理冲突绑定。主角不是只靠猜答案，而是通过模拟、伪装、寻找入口、获取面具、进入急救室等一连串行动完成局部破局。

**强处：** 推理和动作连续，不会出现“主角讲完道理，问题自动消失”的断层。

### 4.5 第六—七章：把已学会的能力迁移到新场景

【正文核验】

第六章将探索空间扩展到广场，并让面具可能具有视觉信息功能；第七章用赌博场景测试主角的观察和推演能力。

**节奏作用：** 前一单元解决一个问题，后一单元不只是重复同一题型，而是把能力迁移到新类型的博弈。

### 4.6 第八—十章：新规则带来的失败回潮

第八章已有正文片段，能确认治疗室、鹿首人等新危险及多次推演受挫。第九、十章当前只有二手摘要，涉及买家/卖家、衣物或纸箱等细节，均须回原文确认。

**分析重点：** 当读者已经相信主角会推演破局时，作者重新提高难度，证明能力并不等于全知。真正的悬念来自“主角漏掉了什么”。

## 05｜可借鉴手法清单

### A类：可直接迁移的结构机制（换掉具体内容）

| 编号 | 手法 | 作品中的表现 | 可迁移模板 |
|---|---|---|---|
| A01 | 先呈现异常实体 | 血迹、残肢、异常房间 | 先给可触摸/可见的异常，再解释背景 |
| A02 | 金手指成本化 | 推演消耗精神力 | 每次使用能力都要消耗可见资源 |
| A03 | 目标阶梯 | 生存/逃离/真相 | 同一任务设置底线、进阶、终极目标 |
| A04 | 规则冲突 | 手册与血字、流程与救人 | 两条各自有理由的规则形成两难 |
| A05 | 失败换信息 | 推演失败后修正路线 | 每次失败至少排除一种可能或增加一个条件 |
| A06 | 道德困境 | 是否救助病友 | 把规则题转成价值选择题 |
| A07 | 第三解法 | 伪装、偷面具、绕过常规流程 | 不在A/B中二选一，而是改变身份/场景/条件 |
| A08 | 道具多功能 | 面具改变观察视角 | 道具同时影响行动权限与信息获取 |
| A09 | 能力迁移 | 推演用于赌博识破出千 | 同一能力跨场景解决不同类型问题 |
| A10 | 细节反杀 | 后续治疗室细节遗漏（待核） | 在看似完整的计划中留一个执行变量 |

### B类：需要改造后使用

1. **国家直播/观众围观**：可借鉴公共 stakes 与信息传播，但必须避免观众只负责复述主角聪明。
2. **规则清单**：规则数量应服务推理，不宜堆叠成记忆竞赛。
3. **反复死亡模拟**：要压缩重复过程，只保留改变判断的关键分支。
4. **怪异NPC**：每个NPC最好有明确的规则职能、利益或行为模式，不只是造型恐怖。

### C类：不建议照搬

1. 直接复制“医院+病人手册+血字”这一整套具体桥段；
2. 让主角每次遇到问题都无限次推演，且没有现实执行风险；
3. 用旁白直接宣布规则真相，跳过读者可参与的推理；
4. 让NPC只会机械执行规则，不具备策略、欺骗或误导能力；
5. 每个副本都用同一种“发现矛盾—推演—破解”节奏，造成公式化。

## 06｜可迁移的章节与单元模板

### 6.1 规则怪谈单章模板

1. **章首钩子**：一个具体异常、禁令或反常行为。
2. **即时目标**：主角本章必须完成一件可判断成败的事。
3. **规则输入**：给出一到两条关键规则/证词/现场信息。
4. **矛盾暴露**：让规则之间或规则与现实发生冲突。
5. **主角假设**：明确提出一个可验证的解释。
6. **验证行动**：观察、试探、询问、伪装或推演。
7. **代价/失败**：假设不成立，或行动引发新危险。
8. **信息增量**：至少得到一个可复用事实。
9. **局部选择**：主角做出有代价的行动。
10. **章末钩子**：新异常、新规则或旧线索的反向解释。

### 6.2 副本单元模板

- 入口：异常空间 + 生存压力；
- 规则建立：给出规则文本及执行后果；
- 初次误判：让主角或读者相信一个看似合理的解释；
- 规则冲突：出现第二份信息源；
- 试错：主角用有限资源排除错误路线；
- 中段升级：空间、身份、时间或NPC策略发生变化；
- 反转：先前线索获得新解释；
- 终局行动：用可见行动兑现推理；
- 余波：奖励、损失、角色关系变化；
- 长线钩子：揭示更大谜面的一角。

### 6.3 推演场景自检表

- [ ] 推演前是否有明确问题？
- [ ] 是否只模拟关键分支，而不是把所有可能性都写一遍？
- [ ] 每次失败是否产生新信息？
- [ ] 推演成本是否对后续决策产生影响？
- [ ] 是否存在推演无法覆盖的现实变量？
- [ ] 现实执行是否需要主角付出勇气、时间、身份或道德代价？
- [ ] 结果是否改变了人物关系或副本状态？

## 07｜文风与语言档案

### 7.1 当前可做与不可做

当前未取得足量连续原文，无法可靠统计：
- 平均段落长度；
- 平均句长；
- 对话占比；
- 心理描写占比；
- 感叹号、省略号、破折号等标点密度；
- 每章字数分布及章末钩子类型占比。

因此本节不伪造量化结果。

### 7.2 可观察到的开篇表达倾向

【正文片段观察】
- 开头偏向短句、名词性视觉信息，迅速建立空间质感；
- 规则以文本/告示/手册等可见媒介出现；
- 推理过程依赖具体动作和场景，而不只依赖抽象分析；
- 章节标题常以“事件/方法/疑问”组织，读者容易预期本章任务。

### 7.3 后续量化建议

取得完整文本后，按 `novel1` 的文风档案口径做本地统计：
1. 先统计全书章节字数分布；
2. 抽样开篇、单元中段、高潮、收尾各若干章；
3. 统计段长、句长、对话比例；
4. 标记章首钩子和章末落点；
5. 将“观察到的语言特征”与“作者写作建议”分开，不把个别章节风格当成全书规律。

## 09｜最终创作结论

### 9.1 这部作品最值得学习的不是“无限推演”这个点子

真正值得学习的是它把能力、规则、成本和行动组合成一个闭环：

**主角不知道 → 提出假设 → 付出资源推演 → 失败换信息 → 修正规则模型 → 现实行动 → 新变量打破安全感。**

### 9.2 写同类题材时，最重要的四个问题

1. **规则是否可推理？** 读者是否能凭已给信息参与判断？
2. **能力是否有限制？** 主角是否必须决定把资源花在哪个问题上？
3. **失败是否有收益？** 失败是否留下新证据，而不是单纯拖时长？
4. **答案是否要行动兑现？** 解谜是否最终要求角色冒险、选择或牺牲？

### 9.3 总结公式

**规则怪谈的可读性 = 异常的具体性 × 规则的可检验性 × 信息差的公平性 × 失败的信息收益 × 终局行动的代价。**

这是一份“当前可核验版拆解档案”，不是全书逐章精读的最终版。后续取得完整正文后，应优先补齐第2章与第9—10章，再按目录逐个副本建立卷级总览和章节卡，最后追加全书伏笔回收表与文风量化档案。
