## 档案维护原则

- 一个章节范围只设一个正式章节分析主档。
- 专题补充档、用户正文底本、历史导航页分别标明身份，不重复计为章节主档。
- 章节主档保存剧情分析；专题档保存跨章节综合结论；来源文件记录证据出处。
- 区分正文支持、结构推断和原作未解，不用推断填补原作留白。
- 历史审计记录用于追溯，不自动代表当前状态。
- 当前进度以02为准，执行顺序与验收状态以05为准；章节事实以对应章节主档为准。

## 证据边界

“分析材料触及第1—589章/篇”仅表示现有档案涉及的范围，不代表每章均有完整正文或已完成全文精读。正文片段、目录信息、用户底本和结构推断须按各自证据范围使用。原作未解释的问题可以保留为开放问题。
